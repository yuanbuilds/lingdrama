# LingDrama 对外展示手册

## 展示前 3 分钟

1. 访问正式 HTTPS 地址，确认首页主视觉和右侧《第59秒》播放器出现。
2. 打开「成果展厅」，播放成片并拖动到约 36 秒，确认画面和声音正常。
3. 使用平台管理员账号登录，确认右上角可见 LingDrama Operations。
4. 依次打开「项目」「资产」「任务」，再进入《第59秒》剧集工作台。
5. 在用户菜单中切换一个客户工作区，确认项目和 AI 使用轨迹随工作区变化。
6. 演示路径不进入「系统设置」；该区域仅供部署负责人维护连接参数。

## 建议 5 分钟演示路径

1. **首页（30 秒）**：介绍从故事、角色、场景、分镜到最终交付的一体化生产链。
2. **成果展厅（60 秒）**：播放《第59秒》，强调 48 秒横版母版、竖版交付、双语字幕与声音设计。
3. **制作工作台（90 秒）**：展示 6 个镜头、角色与场景连续性、图片/视频/合成状态。
4. **资产和任务（60 秒）**：展示真实生成资产、完成任务及 DeepSeek Pro 使用轨迹。
5. **多工作区（60 秒）**：切换不同区域的制作人空间，说明数据隔离与各自项目痕迹。

## 现场边界

- 不在公开页面、投屏文档或聊天窗口展示 API Key、服务器密码或账号密码。
- 系统设置仅供部署负责人维护，不纳入公开展示；客户账号没有系统配置权限。
- 展示期间优先使用已完成资产和成片。若现场演示实时生成，先用最小任务并保留已完成作品作为兜底。
- 若浏览器保留旧缓存，先硬刷新一次；仍异常时使用无痕窗口重新打开正式 HTTPS 地址。

## 快速验收

```bash
curl -fsS https://PUBLIC_IP/api/v1/health
curl -fsSI https://PUBLIC_IP/static/flagship-59s/masters/the-59th-second-16x9.mp4
```

预期：健康接口返回 `status: ok`，成片支持 HTTP Range（播放器请求通常返回 `206`）。

账号密码属于私密运行材料，不写入 Git 仓库；由部署负责人单独保管和交付。
